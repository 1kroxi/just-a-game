В данном репозитории реализована аеб-игра на развитие внимания и реакции. Нужно последовательно нажимать на числа от 1 до 16 в правильном порядке. С таблицей лидеров и системой регистрации.



## ✨ Функционал

- **Регистрация и вход** - создайте аккаунт, чтобы сохранять результаты
- **Игровое поле 4×4** - числа перемешиваются в случайном порядке
- **Таймер** - засекает время прохождения
- **Таблица лидеров** - топ-10 лучших результатов
- **Автосохранение** - результат записывается сразу после победы

## 🛠️ Технологии

### Backend
- **Node.js** - среда выполнения
- **Fastify** - веб-фреймворк
- **Pug** - шаблонизатор
- **Session cookies** - для авторизации

### Frontend
- Чистый **JavaScript** 
- **CSS** - адаптивная вёрстка

### Хранение данных
- JSON-файлы (`users.json`, `results.json`) — не требуется установка БД

## 📦 Установка и запуск

### 1. Клонируйте репозиторий

### 2. Установите зависимости
npm install
### 3. Запустите сервер
node server.js
